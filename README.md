# NextGen Pharmacy

Project Title:  Rays Pharmacy – AI-Powered Smart Pharmacy Platform

You are an award-winning Senior Full Stack Developer, UI/UX Designer, Motion Designer, and Product Designer with over 10 years of experience building premium healthcare SaaS products. Your task is to design and build a production-quality pharmacy website that looks like a premium startup product rather than a college project.

Primary Goal

Create a modern, colorful, premium, and futuristic pharmacy website called NextGen.

The website should immediately impress users with beautiful animations, smooth transitions, colorful gradients, interactive cards, glassmorphism, modern dashboards, and premium motion effects.

Avoid plain white websites, dull colors, or generic Bootstrap designs.

The website should feel like a combination of Apple, Stripe, and a futuristic healthcare startup.
